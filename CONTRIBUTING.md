# Contribuindo para o Pasi Mandarim

Obrigado por considerar uma contribuição. Pull Requests são voluntários e bem-vindos; a AGPL não exige que forks retornem alterações ao repositório original.

## Fluxo básico

1. Faça um fork e crie uma branch para a alteração.
2. Mantenha a mudança focada e documente qualquer fonte externa adicionada.
3. Instale dependências com `npm install`.
4. Execute `npm run typecheck`, os testes relevantes (`npm run test:e2e`) e `npm run build`.
5. Abra um Pull Request descrevendo o problema, a solução e a validação realizada.

## Conteúdo, dados e áudios

Não envie material de terceiros sem origem e licença claramente verificáveis. Preserve autor, URL, licença, obrigações de atribuição e restrições de redistribuição. Atualize `THIRD_PARTY_NOTICES.md` quando a contribuição introduzir ou alterar um recurso externo.

Para correções linguísticas ou fonéticas, explique a fonte e a variante de mandarim a que a observação se aplica. Para interface, priorize clareza, acessibilidade e português brasileiro.
