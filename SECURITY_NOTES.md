# Segurança

O guia de pronúncia não renderiza HTML proveniente de arquivos Anki.

O `.apkg` usado como referência foi analisado apenas para entender a estrutura pedagógica. Os textos exibidos pela aplicação são dados tipados e controlados pelo próprio projeto, renderizados normalmente pelo Vue.

As imagens originais do deck não foram incorporadas porque sua licença não estava identificada. Os diagramas de posição da língua são SVGs próprios do Pasi Mandarim e não carregam conteúdo externo.

Os links de referência externos são abertos com `target="_blank"` e `rel="noreferrer"`.
